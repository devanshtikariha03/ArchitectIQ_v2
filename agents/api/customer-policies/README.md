# API Customer Policy Pack

Place customer-approved API, integration, gateway, service-contract, eventing, partner, and replay policies in this folder.

Use this format:

```md
# Customer API Policy Name
ID: customer-api-policy-id
Tags: api, gateway, integration, contract
Version: 2026.07
Owner: Customer API/platform owner
Effective-Date: 2026-07-17
Review-By: 2027-01-17

## Controls
- Customer-approved API control.

## Risks
- Customer-specific API risk.

## Validation Needed
- Evidence needed before this policy can be treated as verified.

## Citations
- Source reference or policy citation.
```
