## Controls
- Admin/support UI must use least privilege, redaction, maker-checker approvals, reversible operations, audit trails, bulk-action safeguards, and operational dashboards.

## Risks
- Privileged backoffice UI can mutate customer, order, inventory, price, promo, refund, and support data if controls are weak.

## Validation Needed
- Confirm privileged roles, maker-checker gates, audit fields, redaction, rollback, bulk-action limits, and support-access evidence.

## Citations
- ArchitectIQ UI baseline: privileged UI workflows require approval and audit evidence.
