## Controls
- Govern design tokens, components, forms, error states, content patterns, accessibility checks, localization, and visual regression.
- Include checkout, admin, support, mobile, and marketplace/partner surfaces in design-system scope.

## Risks
- Uncontrolled UI components can create inconsistent behavior, accessibility gaps, and slow regional rollout.

## Validation Needed
- Confirm WCAG target, keyboard/screen-reader coverage, locale/currency rules, component ownership, and regression gates.
