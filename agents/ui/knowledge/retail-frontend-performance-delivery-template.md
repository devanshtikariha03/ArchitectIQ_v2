# Retail Frontend Performance Delivery Template
ID: retail-frontend-performance-delivery-template
Tags: performance, cdn, image, web-vitals
Version: 2026.07

## Controls
- Set budgets for Core Web Vitals, bundle size, route hydration, image delivery, CDN caching, edge rules, third-party scripts, and mobile networks.
- Tie performance budgets to conversion, checkout, search, and campaign-launch acceptance tests.

## Risks
- Large bundles, unoptimized images, and third-party scripts can damage conversion and inflate CDN/observability costs.

## Validation Needed
- Confirm performance budgets, CDN/image rules, third-party script governance, mobile network tests, and synthetic peak monitoring.
