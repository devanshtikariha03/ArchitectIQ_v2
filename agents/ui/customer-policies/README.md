# Customer UI Policies

Place approved customer UI, frontend, design-system, accessibility, session, observability, and experimentation policy files here.

Each markdown file should include:

- `ID:`
- `Tags:`
- `Version:`
- `Owner:`
- `Effective-Date:`
- `Review-By:`
- `## Controls`
- `## Risks`
- `## Validation Needed`
- `## Citations`
