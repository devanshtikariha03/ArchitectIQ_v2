# Technology Customer Policy Pack

Place customer-approved technology, API, storage, AI, UI, integration, data-flow, and NFR policies in this folder.

Use this format:

```md
# Customer Technology Policy Name
ID: customer-technology-policy-id
Tags: technology, api, storage, ai, ui
Version: 2026.07
Owner: Customer architecture owner
Effective-Date: 2026-07-17
Review-By: 2027-01-17

## Controls
- Customer-approved technology control.

## Risks
- Customer-specific technology risk.

## Validation Needed
- Evidence needed before this policy can be treated as verified.

## Citations
- Source reference or policy citation.
```
