# Customer Compliance Policy Packs

Place customer-specific compliance, legal, privacy, processor, residency, retention, and audit-evidence policies in this folder during private deployments or controlled evaluations.

Each file can include:

- `ID:`
- `Version:`
- `Effective-Date:`
- `Review-By:`
- `Owner:`
- `Tags:`
- `## Controls`
- `## Risks`
- `## Validation Needed`
- `## Citations`

The Compliance Agent ingests these files alongside the built-in ArchitectIQ compliance knowledge pack. Keep customer policies approved, versioned, and review-dated; otherwise the agent marks them partial, stale, or needing review.
