# Storage Customer Policy Pack

Place customer-approved storage, database, cache, search, object storage, backup, retention, residency, and data ownership policies in this folder.

Use this format:

```md
# Customer Storage Policy Name
ID: customer-storage-policy-id
Tags: storage, database, cache, search, backup
Version: 2026.07
Owner: Customer data/platform owner
Effective-Date: 2026-07-17
Review-By: 2027-01-17

## Controls
- Customer-approved storage control.

## Risks
- Customer-specific storage risk.

## Validation Needed
- Evidence needed before this policy can be treated as verified.

## Citations
- Source reference or policy citation.
```
