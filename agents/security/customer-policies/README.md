# Customer Security Policy Packs

Place customer-specific markdown policies in this folder during private deployments or controlled evaluations.

Each file can include:

- `ID:`
- `Version:`
- `Effective-Date:`
- `Review-By:`
- `Owner:`
- `Tags:`
- `## Controls`
- `## Risks`
- `## Validation Needed`
- `## Compliance Mappings`
- `## Citations`

The Security Agent will ingest these files alongside the built-in ArchitectIQ security knowledge pack.
