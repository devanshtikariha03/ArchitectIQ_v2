# Customer Governance Policy Packs

Place customer-specific architecture governance, decision, rollout, operating-model, systems-of-record, and approval policies in this folder during private deployments or controlled evaluations.

Each file can include:

- `ID:`
- `Version:`
- `Effective-Date:`
- `Review-By:`
- `Owner:`
- `Tags:`
- `## Controls`
- `## Risks`
- `## Validation Needed`
- `## Citations`

The Governance Agent ingests these files alongside the built-in ArchitectIQ governance knowledge pack. Keep customer policies approved, versioned, and review-dated; otherwise the agent marks them partial, stale, or needing review.
