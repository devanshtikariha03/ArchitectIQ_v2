# AI Customer Policy Pack

Place customer-approved AI, RAG, model, vector DB, tool, privacy, safety, eval, and cost policies in this folder.

Use this format:

```md
# Customer AI Policy Name
ID: customer-ai-policy-id
Tags: ai, rag, model, vector, safety
Version: 2026.07
Owner: Customer AI/platform owner
Effective-Date: 2026-07-18
Review-By: 2027-01-18

## Controls
- Customer-approved AI control.

## Risks
- Customer-specific AI risk.

## Validation Needed
- Evidence needed before this policy can be treated as verified.

## Citations
- Source reference or policy citation.
```
